# Agent Note: 普通候选前缀续跑借用 KV

Status: implemented

## Problem

`TailRun::resume` 对普通已计算位置逐层复制截断后的 KV，随后 `run_tail_states` 为追加新位置再次复制这些 KV。前一次复制只用于本次同步调用，既不修改状态，也不需要在调用后持有。

## Decision

内部 `Prefix` 的各层 KV 使用 `Cow<[Vec<f32>]>`。普通续跑借用旧候选的完整 KV，显式 `length` 限定可见位置；前向入口只复制每层可见部分一次。独立上文和真正经过待处理末位置的拼接仍拥有自己的 KV。公开 API、权重、计算次序、隐藏状态共享及缓存生命周期不变。

## Existing decisions

已检索活跃笔记中的 `Prefix`、`resume`、KV 和借用。[末位置按需前向](../../implemented/bug-fix/2026-10-15-defer-terminal-forward.md)继续规定末位置只保存新增一行，本片只减少普通位置临时复制；[完整命中缓存](../../implemented/bug-fix/2026-10-15-identical-rerank-cache.md)与[共享归一化](../../implemented/bug-fix/2026-10-15-shared-state-normalization.md)继续约束共享状态。外层状态缓冲和分数缓冲属于独立容器，无需修改。没有完全吸收的笔记或过时提案。

## Alternatives considered

- 把全部 KV 改成 `Arc` 并共享：可统一共享所有权，但需要重写新增位置和末位置拼接的持有规则；当前临时前缀只需同步借用。
- 为普通前缀另建视图和分派类型：可以保留缓存前缀原类型，但会增加一组平行字段和入口；`Cow` 允许同一私有结构表达借用与拥有两条路径。
- 继续复制：没有生命周期参数，但每次普通共享前缀续跑重复复制同一段只读数据。

## Verification

`ordinary_resume_borrows_the_existing_kv_storage` 在旧实现因外层地址变化失败，借用后通过。`borrowed_resume_matches_a_truncated_owned_prefix` 覆盖全部普通截断位置和末位置、一个至三个后继 token，逐位核对累计分并比较 KV、隐藏状态；临时去掉可见长度截断后测试实际失败，恢复后通过。

Rust 1.97.1 与最低版本 1.75.0 均通过 30 个单元测试、14 个模型文件测试和 doc tests；全目标 Clippy（`-D warnings`）、Rustfmt 和差异检查通过。既有三精度模型、跨轮状态与缓存寿命回归继续通过。

## Measurements

本机 ARM64 release，以固定 `42bad7174929fb2f3aece665e1fdbe7f30c667fc` 为旧版，模型 SHA-256 为 `86ac529510cb3b4968a5e6ade83ec8080f5b34a0a681e75c362accbbd387d1c1`，使用主项目 `resources/eval/sentences-nine-key-v1.tsv` 的 81 条固定句子。两臂各运行 `reference/examples/bench.rs`，每形状 40 次；本任务没有同时运行其它编译或基准。十五字列没有足够长的输入，原程序输出零，该列不能当作有效测量；逐字打字表的十五字行也不能代表完整十五字请求。

九候选、十二字、只改末字的热续跑 p50 从 0.077 ms 到 0.034 ms；这只是局部路径的两轮测量，不能推断端到端收益。新版冷计算九候选八字、十字的 p95 有明显离群，完整保留，不把它解释为稳定的回退或收益。主项目接入仍需九键逐键实测。

## Consequences

普通续跑少两份外层向量和每层两份 KV 行复制。借用生命周期只覆盖同步评分，不进入持久缓存、不增加 `Arc<TailRun>` 的持有期；独立上文与末位置拼接仍拥有 KV。内部 `Prefix` 增加生命周期参数和 `Cow` 的拥有/借用分支。

借用数组可能含未来 KV，空前向及非空前向复制入口都必须按 `length` 截断。末位置拼接暂时仍有复制，不在本片扩大改动。权重、矩阵点积、归一化和候选提升规则保持；九键 16 ms 目标继续保持 active，主项目必须另行固定提交并验证。
