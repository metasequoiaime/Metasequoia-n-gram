# Agent Note: 同一次前向复用前馈层临时缓冲

Status: implemented

## Problem

主项目固定 `328e348374`、本库固定 `cc1d3dd` 的二十秒九键采样仍以 `linear` 与 `dot_i8` 为主要热点，申请和释放也在实际调用树。每个前馈层独立申请归一化、四倍宽隐藏层和投影输出三个向量，六层模型在同一次前向重复这些相同大小的申请。归一化结果生成隐藏层后已不再使用，可以承接输出投影。

## Decision

同一次 `run_prefix` 或非空 `run_tail_states` 创建两份局部备用向量，在各层前馈之间复用。归一化写入第一份，第一线性层写入第二份，GELU 原位更新，再用第一份承接第二线性层输出并加回残差。调用结束即释放，不增加跨轮缓存、共享模型可变状态、unsafe、依赖或最低 Rust 版本。点积、缩放、bias、GELU、残差相加和所有归约顺序保持。

## Existing decisions

已检索 `scratch`、前向缓冲、`layer_norm` 和 `feed_forward`。[最终 KV 存储](../../implemented/testing/2026-10-16-packed-tail-kv.md)部分相关，继续持有 KV 构造与可见长度；其备选拒绝的是跨轮持久化前向工作区，本片限定同一次同步调用。外层分数、候选状态和编码所有权各有独立笔记；行分派、四行交错继续保留负结果，本片不改变矩阵内核和权重表示。没有完全吸收或过时提案。

[Vec 官方文档](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.resize)说明长度和容量的区别；复用时仍完整写入每个输出，不能让旧元素参与当前计算。同仓库 `scores_scratch` 已使用局部接管后清空的模式，但本片缓冲不会跨调用持有。

## Alternatives considered

- 跨轮持有完整前向工作区：可复用更多申请，但扩大 `Reranker` 状态、需要同步公开直接评分入口且增加持有峰值。本片只复用同一次调用中的等形状缓冲。
- 改用固定数组或全量展开权重：可以减少运行时形状判断或转换，但模型几何可变，键盘扩展内存边界继续要求保留量化权重。
- 仅复用输出而每层重新归一化申请：接口改动少，但归一化与输出寿命不重叠，两份存储足够覆盖原三份。

## Verification

先线程化局部工作区、内部保留旧拥有型计算时，暖缓冲地址稳定回归真实失败（1 passed、1 failed、2 ignored）；改为写入型 helper 后为 2 passed、0 failed、2 ignored。冻结 `cc1d3dd` 的旧完整前馈、linear、layer_norm 和两条前向路径，Float/Quantized、宽 1/7/8/9/192/768、行数 0/1/4/12/4/1/0、三层残差的每层输出全部逐位一致，缓冲地址和容量稳定，缩小后旧数据不可见。

release 完整六层前馈链每形状 40 对，交替先后，旧臂校准至少 10 ms，包含输入复制、工作区构造和析构。量化宽 192 单行主形状预定比值小于 0.99，其他小于 1.03，收集全部形状后统一判断，未改预算或筛样本。独占计时全程未观察到并行构建，全部通过：

## Full model benchmark

固定模型 SHA-256 `86ac529510cb3b4968a5e6ade83ec8080f5b34a0a681e75c362accbbd387d1c1`、九键 81 例，release `bench` 每形状 40 次。旧版来自干净 `cc1d3dd`，新旧二进制 SHA-256 分别为 `02f1630064e4c58e8f1f85d7143f8a56b3808e8bb8ab779f721a0054cde47980` / `3c80574a2edf519a6c7ab32b524f54bfc775ddc9f2a4ed02a12087b2c5f48219`。十五字决策列没有样本，0 值无效；逐句表十五字行也不能解释为真实十五字决策。

## Consequences

六层前馈主形状约少 1.5% 耗时；写入型 helper 可能改变编译器内联和初始化，局部收益不能推断完整推理更快。两份缓冲合计 5N 个 f32 的容量会跨下一层 attention 存活，因此不能宣称完整前向峰值内存下降。归一化输出不能在第一线性层结束前覆盖。工作区必须局限于当前前向，不进入模型共享状态或 KV 缓存。
