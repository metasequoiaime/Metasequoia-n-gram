# Agent Note: 完全命中的重排候选复用完整推理状态

Status: implemented

## Problem

`Reranker::score` 把共享前缀限制为候选长度减一，同一上下文和候选跨轮完全不变也重算末字并复制 KV、隐藏状态。上一轮 `TailRun` 已保存完整累计分，重复计算没有提供新信息。

## Decision

上一轮候选状态由 `Arc<TailRun>` 持有，编码及截断后的 token 完全相同时复用状态和累计分；部分匹配继续沿用既有续算。缓存仍只保留上一轮，前缀 token 改变时全部失效。公共接口、评分单位、门控和候选预算保持不变。

部分共享位置的概率归一化由[共享状态归一化](2026-10-15-shared-state-normalization.md)补充；完全命中和上一轮缓存寿命继续遵循本篇。

末位置的前向由[候选末位置按需计算](2026-10-15-defer-terminal-forward.md)补充：缓存保留完整累计分，KV 和隐藏状态在续跑经过末 token 时补齐；本篇的共享与失效约束继续成立。

## Alternatives considered

- 移动旧状态：无需引用计数，但同一批其它候选可能仍要从这个状态续算，提前取走会破坏复用。
- 深复制完整状态：可以省推理，但仍复制 KV 与全部隐藏状态。
- `Rc` 共享：引用计数便宜，但会破坏公开重排器既有的 `Send`、`Sync` 能力。

## Verification

旧实现的 `identical_candidates_keep_the_completed_run` 因累计分存储被重建失败，修复后通过；回归同时检查隐藏状态地址、重复候选共享、缓存清空后释放状态与 `Send + Sync`。三种精度覆盖重排、增删、部分续跑、上下文失效、空、未知字符和超窗口截断，与冷评分和首选一致。Rust 1.97.1 与 MSRV 1.75 均通过 26 项测试，Clippy 全目标、fmt 和差异检查通过。

固定 msime 模型（4.5 MB、`model-v1`）对照旧固定提交 `7e02487323ee5047a07a36b6e20d766d7c2f381d`（评分逻辑与本次 `main` 基线相同）。141 条合成全拼用例的前九候选经缩短、恢复、重复、倒序、恢复五轮共 705 轮、6335 分数；九键 81 条共 405 轮、3645 分数。首选全部一致，最大绝对差分别为 4.7683716e-7 和 0。使用既有字符数代理和词典来源门控的离线回放中，全拼词典桶 9/9 → 9/9，解码器桶 104/131 → 104/131；九键词典桶 7/7 → 7/7，解码器桶 43/74 → 43/74。这里验证评分缓存，不代表该代理适合所有宿主。

## Consequences

完全命中省去末字推理、完整词表归一化与状态复制；新计算的状态增加一次 Arc 分配及引用计数开销。只保留上一轮候选，每轮条目数继续由入参控制，不新增跨轮无界缓存。部分续算已有浮点求和分组误差，完全复用可能保留与旧重跑不同的末位；上述质量与误差对照限制这个风险。微基准不代表九键宿主已通过 16 ms 预算，需要在主项目继续验证。
