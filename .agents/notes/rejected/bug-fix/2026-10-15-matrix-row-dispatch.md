# Agent Note: 矩阵一次投影只判断一次权重类型

Status: rejected — 完整线性层的配对预算未通过，局部收益不足以支持接入

## Problem

线性层和完整词表投影逐行调用 `Matrix::dot_row`，每个输出重复判断权重类型、计算并检查整表范围。实际 ARM64 指令已经向量化，继续改变点积形状未必提速。四行交错已有负结果，不能重复靠循环改写猜测收益。

## Proposal

矩阵内部增加批量行访问：先确定本次行数与完整字节范围，按 Float 或 Quantized 分支遍历连续权重行，将目标迭代器元素和原点积结果交给调用者。线性层仍写原结果槽并加 bias；完整投影仍按原顺序更新最高值和追加 logits。单 token 查询继续使用原 `dot_row`。不改变八部分和、缩放、归约、全词表归一化、权重表示或缓存，不增加依赖或 unsafe，维持 Rust 1.75。

## Existing decisions

已检索矩阵、`dot_row`、归一化与量化笔记。[行交错负结果](../../rejected/bug-fix/2026-10-15-matrix-row-batching.md)拒绝跨行累加调度，继续保留；本项只合并类型判断与范围检查，不改变点积。[共享归一化](../../implemented/bug-fix/2026-10-15-shared-state-normalization.md)继续约束投影次数与状态寿命，本项仅改变每次已有投影的行遍历。

## Alternatives considered

- 增加每行部分和数量：能增加独立计算链，但改变舍入。在当前合成配对测试中，192 宽的 16/32/64 路分别为旧版的约 1.02/1.41/3.94 倍；16 路只有 768 宽为 0.846，不能覆盖主路径，不采用。
- 192/768 固定宽度数组特化：保留位模式，编译器可见固定几何；实测比值 1.000–1.007，无收益，不增加专用分支。
- 扩展为 f32 常驻或手写架构内核：前者增加键盘扩展常驻内存，后者违反当前 crate 的 unsafe 禁止边界。保持现有量化表示和标准库迭代。

## Acceptance criteria

- 实际生产调用形状的配对手工预算在旧实现失败，新实现有收益；不能只凭无 bias 的原型提速落地。
- Float 与 Quantized、短行、奇数宽度、八路边界、空输出和多输入行逐位对照旧线性层；真实模型所有评分、排序与公开分布保持。
- 完整 benchmark 表、MSRV、全量测试、Clippy、fmt；上游先独立提交合并，再用固定提交接入主项目，完成质量和九键逐键计量及 quick 后合并接入 PR。

## Risks

调用者闭包可能重新引入结果槽边界检查，实际收益可能低于原型的 1%–4%；需以真实调用形状决定是否保留。不能把局部矩阵收益等同于九键 16 ms 目标通过。

## Measurements

固定基线 `0ed28cf0a254a426ea7bf4ccf21a6c3239e3166d`，本机 ARM64 release 构建。完整 `linear` 对照包含输出分配、原点积、逐行 scale、bias 与结果槽写入。每形状 80 对，每臂 50 次，每对交换先后顺序，表中为逐对 new/old 的中位数。合成非均匀权重和输入，先逐位核对每个计时形状的输出。

原型提前按 Float/Quantized 分支，通过 `chunks_exact(width)` 遍历权重行，再与调用者提供的目标迭代器 zip；`linear` 的目标是可变结果槽与 bias 的 zip，闭包写 `value + bias`。原八部分和及归约顺序均不变。对照函数是固定基线的完整 `linear`，两臂用 `inline(never)` 包装，通过函数指针和 `black_box` 调用。

```text
quantized width rows paired_ratio_p50
true      192   576  0.9891
false     192   576  0.9948
true      192   192  0.9848
false     192   192  0.9945
true      192   768  0.9890
false     192   768  0.9957
true      768   192  1.0016
false     768   192  0.9725
true      192  8192  0.9846
false     192  8192  0.9972
```

事先设定 192 宽比值小于 0.99、768 宽小于 1.03 的预算，全部形状收集后统一断言，结果失败；不能把未通过的形状去掉或放宽预算。相同量化主形状另一次运行得到 0.9919，也未达标，收益接近本次测量噪声。更早仅按行号回调再索引结果槽的版本为 1.0087，已回退。

无 bias、直接写输出的初始原型在 192 宽量化为 0.965–0.970、浮点约 0.957–0.960，768 宽量化约 0.991。该原型遗漏真实调用成本，其收益不能用于决定生产接入。

没有运行完整模型 benchmark、真实模型质量对照、MSRV 或完整测试，不据此断言完整推理有收益或没有收益。保留原生产代码，删除未达预算的实现与临时测试；本次只归档负结果。单独的 `project` 调用仍未验证，不能用上表冒充其结果。
